# Bilibili 宣传片交付

推荐投稿文件：`成片/云溪古镇_宣传片_含功能与三时段.mp4`、`成片/清明上河图_宣传片_含功能与三时段.mp4`。

每条约 70 秒，1920×1080、30 fps、H.264 视频 / AAC 立体声。原始 Canvas 录制约 1270×726（风景）、1280×720（功能），成片缩放到 1080p，不宣称原生 1080p 采集或恒定原生 30 fps。录制来自实际运行的 WebGL 场景，不是静态截图推拉。

## 内容时间轴

- 00:00–00:21：片名与三组场景运镜。
- 00:21–00:28：自由漫游，调用原有键盘输入链路行走。
- 00:28–00:35：地图与地标定位。
- 00:35–00:42：人物开启与动态商贩、行人。
- 00:42–00:49：清晨 / 雨霁的日间效果。
- 00:49–00:56：黄昏暖色光照。
- 00:56–01:03：夜景与灯火。
- 01:03–01:10：全景收尾、访问引导与来源说明。

录制专用页面通过原场景输入、按钮、菜单处理器执行可复现的功能演示；功能段叠加真实地图 Canvas 和状态字幕。为了干净构图，没有把浏览器工具栏和全部菜单 DOM 烧入视频。三时段通过场景自己的光景选项切换，不用剪辑调色冒充昼夜变化。

剪辑使用 FFmpeg，未使用剪映。含淡入淡出、分镜裁切、标题、说明字幕、片尾致谢。配乐由本项目脚本合成的拨弦与低音铺底生成，未引用现成歌曲；没有录制人声旁白，宣传文案和字幕可另作配音稿。

`原始素材/风景/` 为六组风景镜头，`原始素材/` 为功能与三时段录制；原始素材与成片保存在本地并被 Git 忽略，避免大视频进入源码历史。`剪辑宣传片.py` 生成风景版及中间片段，`功能版剪辑.py` 生成投稿完整版；按此顺序运行。42 秒的 `_宣传片.mp4` 是纯风景备选版，投稿优先使用带“含功能与三时段”的文件。

各自的 `B站发布文案.md` 包含标题、简介、标签、封面文字和置顶评论。未代为发布到 Bilibili。
