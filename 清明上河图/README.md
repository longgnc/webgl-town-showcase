# 清明上河图 · 写实优化版

推荐打开上级目录的 `清明上河图_写实优化.html`。`清明上河图_完整漫游.html` 同步为相同内容。初版源码和初版单文件保留在 `versions/初版留档/`。

这是依据画卷构成、故宫资料和用户视频进行的可漫游三维演绎，包含城郊、汴河、虹桥、城门与城内街坊。它不是对画中每座建筑的考古测绘复原。当前程序化建筑仍有重复，植被、货物和室内的精度仍低于扫描资产制作的大型商业游戏。

## 本轮重点

- 人物、商贩默认关闭，按 N 或底部“人物”按钮切换；开启后恢复行走与商贩动作，关闭后隐藏人物并停止其动画更新。牲畜仍关闭。保留船只、水流、风与环境声。
- 六组摄影 PBR：石板、灰瓦、旧木板、灰泥、石墙、泥土。颜色与 OpenGL 法线使用 2K，粗糙度、AO、高度使用 1K。木纹按梁柱长轴投影，墙根有潮渍，石板有湿度变化。
- 近景屋瓦采用有厚度的曲面叠压几何；屋面、山墙统一曲线，修正穿出屋面的顶板。门窗有凹入深度，补足檐下木构。
- 修正店招与檐口、邻屋与庭院装饰、树冠与建筑、货摊器皿之间的冲突；道路交叠区域裁剪，避免重叠面闪烁。
- 补充货摊、棚布、货车和桥栏碰撞；跳跃有头部净空判定，落地能站在货台表面。
- 使用原项目的实际天空、环境捕获、软阴影与后处理代码。具体参数和场景适配见 `画质优化与验收说明.md`。

## 操作

画卷展开、画面渐变后进入开始菜单。可选择鸟瞰、自由漫游或镜头游览。

| 操作 | 按键/入口 |
| --- | --- |
| 行走、奔跑、跳跃 | WASD、Shift、空格 |
| 视角 | 鼠标；首次进入点击画面锁定 |
| 菜单 | Esc 或右上角游览菜单 |
| 鸟瞰 | B；拖动旋转，右键平移，滚轮缩放 |
| 地图 / 最近地标 | M / F |
| 人物开关（默认关） | N 或底部人物按钮 |
| 隐藏界面 | H |
| 材质样板 | 菜单 → 查看材质近景 → 屋檐 / 木构 / 石板 / 水面 |
| 运行检查 | 菜单 → 运行状态与检查 |

默认“原版光影 · 雨霁”“写实 · 原版高画质”。画面偏暗的檐下与暖色斜光来自原项目照明，不是常规正午的均匀打光。可切换黄昏/夜景；这些是场景的艺术扩展。

## 运行与文件

单文件内嵌引擎、纹理、脚本和开场画卷局部图，不依赖 CDN、账号、数据库或业务后端。因加入摄影纹理，体积约 43 MB，首次纹理解码和着色器编译需要等待。建议桌面 Edge/Chrome、开启硬件加速；性能不足可选“均衡”。

源码入口为 `index.html`。也可在本目录运行 `python -m http.server 8770 --bind 127.0.0.1`，访问 `http://127.0.0.1:8770/`。这是本地文件服务，不是业务后端。独立文件通过回环 HTTP 验收；浏览器自动化限制了 file://，因此没有把直接双击列为实测通过。

重新打包，在上级目录执行：

```powershell
python cinematic-webgl-town/scripts/build_standalone.py --project 清明上河图 --output 清明上河图_写实优化.html
```

`scene.js` 是实际运行源文件。`*.part.js` 及部分 `tools/*pass.py` 是本轮开发留档，不应重复执行拼接；素材重嵌入脚本为 `tools/embed_pbr.py`。`vendor/jimao-engine.js` 由用户提供的原项目派生，原件没有被修改。
