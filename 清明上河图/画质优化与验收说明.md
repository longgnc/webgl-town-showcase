# 原版光照对齐与写实优化

## 复用范围

直接复用 `几猫国产3A大作_V1.html` 内 Three.js r180 及其天空生成、PMREM 环境捕获、PCSS 软阴影和 `jy` 后处理实现。并非只在新场景上添加一个颜色滤镜。后处理链含 HDR、深度 AO、体积光、多级 Bloom、自动曝光、运动模糊、色调映射、FXAA、锐化及颗粒。

以下为默认雨霁模式的原版基准：

| 项目 | 数值 |
| --- | --- |
| 太阳方向 | normalize(0.916, 0.225, 0.331) |
| 太阳线性 RGB / 强度 | (1, 0.72, 0.42) / 9 |
| 环境强度 | 2 |
| 高画质阴影 / MSAA | 4096² / 4 |
| Shadow bias / normal bias | -0.00012 / 0.02 |
| 体积光步数 / volSunScale | 24 / 0.85 |
| volAmbient / volSigma | 0.2 / 0.0034 |
| volMaxDist / volFarHaze | 170 / 0.42 |
| AO radius / intensity / strength | 0.9 / 1.6 / 0.95 |
| Bloom / bloomMix | 0.065 / 0.62 |
| 曝光 key / min / max / adaptTau | 0.12 / 0.6 / 2 / 1.5 |
| AgX mix / lookPower / lookSat | 0.25 / 1.18 / 1.22 |
| vignette / grain / sharpen | 0.3 / 0.02 / 0.3 |

完整参数由运行时写入 `#render-audit`，导出到 `evidence/final-render-audit.json`。为城镇尺度适配了相机远平面、随镜头移动的阴影视锥、物体 LOD、水面镜像反射和最大像素比；黄昏/夜景也有额外调参。不能把这些场景适配说成与原版逐项完全相同。新引擎副本内阴影纹理采样指定 LOD 0，以减少 D3D 的导数警告，原始 HTML 保持原样。

## 材质和细节

实际加载 6 × 5 张摄影纹理通道。不是仅把程序噪声放大，也不是把彩色贴图伪装成法线。颜色采用 sRGB，数据贴图使用线性空间。石板按米制纹理坐标铺设，局部高度取自真实 displacement。屋瓦增加曲面与前缘厚度，近景最多加载 16 组精细屋面，远景退回贴图屋面。木材按构件局部长轴投影，并区分端面，解决之前拉伸成横条的问题。

水面采用 HDR 平面倒影、六组小尺度非规则波纹、Fresnel 和随深度变化的吸收色。它仍是实时近似，不是流体模拟或光线追踪。植被仍是程序化表现，未制作扫描树木。

## 检查方式与边界

进行了固定近景、沿河景和最终单文件运行检查。源码版本的 33 项自检已通过：两座桥实际通行、城门通行、8 个出生点、建筑阻挡、桥栏阻挡、河岸边界、货车、落到货台、头部不穿棚布、人物关闭、PBR 加载、后处理启用等。最终打包的结果另存 `evidence/final-selftest.txt`。

建筑布置用包含屋檐和店前区域的有向包围体进行 SAT 检查，当前接受的建筑间无包围体交叠。该证据只覆盖登记的包围体；不能证明所有装饰三角形、所有机位和所有运动路径永远零穿模。可视检查另外修复了屋顶顶板、山墙曲线、店招、院落装饰、棚布和货物间距。

源版本在本机 Edge 约 1432 × 687 视口、高画质下，鸟瞰采样约 23–26 FPS，近景约 30 FPS；这不是全镇保底帧率。摄影材质和原版后处理增加 GPU 与显存负担。初版 `runtime-walk.txt` 中的帧率不代表本轮写实版本。具体最终采样看 `evidence/final-runtime.txt`。

当前仍有浏览器 D3D 着色器编译器对原版采样循环的导数提示；实际渲染可用，检查时未发生 WebGL 编译失败。日志保存于 `evidence/final-console.json`，如新版本已不再复现，以该日志为准。没有进行手机、跨显卡、听觉设备、断网开关或任意路径穷举验收。

## 后续更高精度所需资产

继续接近实拍，需要逐建筑制作的 GLB/FBX、正确米制尺度、独立 UV、摄影 PBR、近中远 LOD、碰撞代理和多角度参考。只有一张画卷或一段视频无法确定所有背面和室内；这些部分应标记为设计补全。当前 skill 可以约束工作质量和检查流程，不能保证任意口述都 100% 还原未知场景。
