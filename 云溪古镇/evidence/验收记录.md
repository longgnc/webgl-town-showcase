# 云溪古镇验收记录

日期：2026-11-12。目标为大理/丽江风格的原创可漫游古镇，不是实测古城重建。

## 交付范围

- 约 640×640 m 镇区地面，步行边界位于 ±318 m 内；建筑与河道占用区域不可直接穿越。
- 484 栋建筑；六座跨河石桥；七个地图地标。
- 279 位动态角色（168 位沿河行人/游客、47 位沿街商贩、40 位集市商贩、24 位广场居民）。仅提交附近人物进行绘制。
- 四方街含 40 个摊位，并保留中间通道。沿街店铺、横匾、竖牌、灯串、花藤、扎染、茶具、陶器和货摊。
- 程序化风、水、鸟、船、声音，三种光景及三档画质。建筑优先：人物默认关闭，按钮/N 键可切换，localStorage 记住选择，关闭后停止人物更新。
- 单文件 1,465,672 字节，约 1.40 MiB；原参考文件 1,425,707 字节，未修改。

## 已完成的检查

1. `node --check`：场景源码通过语法检查。
2. skill-creator 的 `quick_validate.py`：通过。Windows 使用 Python UTF-8 模式运行，避免默认 GBK 解码中文失败。
3. 参考审计脚本实际运行，结果保存在 `reference-audit.json`。
4. 引擎提取脚本实际运行，与交付的 `vendor/jimao-engine.js` 哈希相同。
5. 单文件打包脚本实际运行；在本机 Edge 中通过 HTTP 加载单文件并渲染，未使用外部 CDN。
6. 浏览器中运行 **29 项自检，全部 PASS**。完整输出见 `final-movement-tests.txt`。
7. 自检涵盖六桥逐一通过实际 `walk()` 移动跨河、桥心高度、墙体/河域/边界阻挡、步速 3.8 m/s、冲刺 6.4 m/s、斜向不超速、跳跃落地、蹲下眼高、七处出生点。
8. 自检还通过键盘事件进入原件输入工厂，再调用移动更新，验证 W 与 C 的集成；这是程序事件集成测试，不等于全套人工键鼠测试。
9. 浏览器实际点击进入、暂停恢复、地图定位、光景与画质选项，查看了商街、河道、寺院、地图、清晨和夜景。发现并修正过纹理方向、植被轮廓、场景批处理数量、建筑稀疏、角色密度与夜晚太阳过亮等问题。
10. 人群运动证据：`population-sample-a.txt` 与 `population-sample-b.txt` 中，相同角色的 Z 坐标和动作相位变化；两组截图显示位置与步态不同。观景游客有停留段，不能仅因某一角色短时间不移动判断全部动画停止。
11. 页面运行状态确认 Web Audio 为 `running`；实际收听品质、声场定位没有通过录音/人工试听验证。
12. 抽查的浏览器控制台未出现渲染或 JavaScript 错误。它不是对所有可能设备的零错误保证。

## 性能观察

浏览器可视截图约 1432×766。观测来自用户当前电脑的 Edge，多标签/其他程序同时存在，未执行独占 GPU 的严格 benchmark。

- 最早稀疏原型的远景全量细节绘制曾约 10 FPS、1231 次调用；加入距离分级后，某些早期视角达到 60 FPS。这不是最终完整闹市版的统一指标。
- 中间版本加密至 484 栋建筑、239 人后，精致档样本曾记录约 26–50 FPS、约 500 次调用；进一步裁剪小物件后，抽样绘制调用约 382。实际值随视角、反射帧、角色和编译状态变化。
- 流畅档持续运行后，页面曾显示 60 FPS、约 297 次调用、约 27–28 万可见三角形。
- 最终增加 40 位驻摊商贩至 279 人，四方街集市样本显示 60 FPS、308 次调用、574,671 三角形；这仍是单视角瞬时样本。
- 首次加载或切换画质可能因 shader 编译出现短暂停顿；不能将启动编译期间的帧率当稳态性能。
- 没有承诺全镇恒定 60 FPS；较弱设备可先选均衡或流畅。

## 尚未验证或未实现

- 自动浏览器的 URL 策略禁止直接访问 `file://`，因此没有通过自动化完成“双击本地 HTML”的验证；未尝试绕过该策略。单文件内容已通过本地 HTTP 运行验证。需要时可按项目说明启动静态文件服务。
- 未进行手机、触屏、手柄实机验收。输入模块存在相关分支，不代表这些平台已通过测试。
- 本版本人物为程序化几何和动作，近景仍明显风格化；没有专业骨骼角色、面部捕捉、布料物理或真实录音对话。
- 人群沿预设路径活动，没有完整的全镇导航网格、复杂避让和交易系统，个别人群接近时可能穿插。
- 民居主要是外部场景，未逐栋制作可进入室内。
- 没有进行与参考文件相同机位、相同光照的客观图像对比，不宣称已经达到原件全部画质效果，更不宣称商业 3A 等级或“100% 还原”。

这些限制与已通过的功能验收分开记录。若下一阶段使用高质量 GLB/FBX、PBR 贴图、真实人物动作和原始多视角参考，可以在当前漫游与分块框架上继续提升。
